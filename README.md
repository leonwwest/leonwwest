## Engineering approach

Every core project is designed to be inspectable: the repository explains what is automated,
how it is verified, which decisions were made and where a production implementation would need
additional controls. The projects are reproducible portfolio labs, not claims of operating a
real customer tenant or production cluster.

The fastest review path is: start with the [Azure Platform IaC Lab](https://github.com/leonwwest/azure-platform-iac-lab), then inspect the [GitOps Platform Lab](https://github.com/leonwwest/gitops-platform-lab) and the [Incident Automation Lab](https://github.com/leonwwest/slow-ai-app-incident-lab). Each repository includes a real execution capture, automated verification and explicit production limitations.
